# 首轮 QA：build-v1

**结论：功能 1 项失败，视觉 1 处偏差。** 本地模拟单 R-17，无真实退款，无人工签收。

|前置与动作|预期|实际|结论与证据|
|---|---|---|---|
|客服 / 待审|显示待审，不显示批准入口|显示待审，且显示禁用的「批准退款」|失败：[快照](service-pending.txt)、[可见性](service-pending.json)|
|客服 / 已处理|已处理，无按钮|一致|通过：[快照](service-done.txt)|
|主管 / 已处理|已处理，无按钮|一致|通过：[快照](manager-done.txt)|
|主管 / 待审|待审，批准按钮可用|一致，以 MCP `click` 点击「批准退款」|通过：[点击前](manager-pending.txt)|
|批准一次后|变为已处理，入口消失|已处理，无可重复点击的批准入口|通过：[点击后](after-click.txt)、[截图](after-click.png)|
|同一浏览器分别以主管、客服重开，仅传 `role`|两者均显示已处理、无按钮|一致，固定资料未变|通过：[主管](reopen-manager.json)、[客服](reopen-service.json)|

四个显式 `?role=…&state=…` 入口在隔离浏览器内首次点击前检查。各入口及重开均保留 R-17、青禾路店、¥28.00、配送少了一盒餐。结论限于用户界面及该浏览器的持久状态，不证明服务端交易幂等或授权。

**视觉：** [设计截图](design.png)与[开发截图](default.png)均为默认主管待审首屏，设计页是待签收 HTML 参考。按 PNG 解码后逐像素比较 RGBA，任一通道不同即计数；无缩放、无遮罩，不设人为容差。两页各自连拍两张，均为 0 像素波动。[差异图](diff.png)中红色为差异：13,983 / 1,024,000（1.366%），范围 x=811–1130、y=364–432（含边界）。批准按钮顶边从设计的 363.77 移到 383.77 CSS px，下移 20 px；尺寸和背景色不变。
