# 走出独立 App 的边界：基于 Harness 的下一代涨乐随身投顾 Agent 战略与落地方案

> **定位**：面向公司管理层与业务条线的未来 3–10 年前瞻战略及 MVP 立项方案  
> **发起部门**：**用户增长与平台运营部**（全面复用现有公用后端、AI 涨乐及投研基础能力）  
> **战略判断**：基于通用 AI 底座（Harness）与随身 Agent 的服务分发重构，将是**未来三年到十年证券零售业务最重大的范式变革**。我们正处在这场变革的前夕——传统 App 短期内绝不会立刻淘汰，但如果不从今天开始早做准备、重构服务编排能力与人机协同模式，未来必将陷入被动。

## 一、 核心破局点：不要选错对比参照系（从 1.0 → 1.5 → 2.0）

今天讨论券商 AI 创新，最大的认知盲区是还在拿“AI 功能”去和十年前的 **1.0 传统炒股软件（涨乐财富通经典菜单模式）** 做对比。事实上，公司已经推出了 **1.5 代 AI 独立应用（AI 涨乐）**，实现了对话入口、行情资讯新卡片、会话内动态生成盯盘条件单与策略选股。

然而在实际运营中，**“在独立 App 壳子里做 AI”天然受困于四道结构性枷锁**——这正是我们提出 **2.0 代“基于通用 Harness 的涨乐随身投顾 Agent”** 的根本原因：

| 核心维度 | 1.0 传统炒股 App<br>（菜单驱动） | 1.5 独立 AI 炒股 App<br>（以现有 **AI 涨乐** 为代表） | 2.0 Harness 原生随身投顾 Agent<br>（**本方案面向未来 3–10 年的目标形态**） |
| :--- | :--- | :--- | :--- |
| **用户驻留场景** | 仅交易时段打开，层层翻找菜单 | **仍是孤立炒股软件**：没人没事一直泡在里面，日常做本职工作时处于断联状态 | **住进用户全天候电脑/手机工作底座（Harness）**：边干日常工作边无感伴随，突发消息原地一句话即刻交易，**零应用切换** |
| **交互与算力底层逻辑** | 纯本地客户端静态代码 | **“二八长尾重构死结”**：虽然行情、资讯、盯盘条件单等**前 10% 核心功能**已投入重兵做好了动态/预置新卡片；但因集中算力撑不起全量实时生成 UI，剩下 **90% 运营活动（如《智投实盘系列赛》）与长尾非高频业务**根本没时间逐一重构，点进去仍是**千人一面的老式 H5 页面手点** | **个人 Harness 算力解锁全业务“真千人千面”**：依托用户自有 Harness 算力做分布式实时界面生成，无需预先开发静态页面——哪怕是一场**交易大赛**或低频业务，也能根据每位客户画像实时生成专属交互卡片 |

## 二、 三大极具杀伤力的真实体验差异场景

### 场景 A：跨工作流的“无感伴随与原地交易”（打破独立炒股 App 的驻留孤岛）
* **AI 涨乐（1.5）的局限**：绝大多数投资者不是全职交易员。白天他们在电脑/手机的通用环境里写报告、开会、处理日常工作，不可能一直盯着 AI 涨乐。当外部突发重大消息时，等他反应过来、解锁手机、切进 AI 涨乐、再描述诉求，黄金窗口往往已经过去。
* **Harness + 涨乐 Agent（2.0）的有机体验**：
  1. 用户早上打开日常工作用的 **Harness** 处理公务，只顺嘴交代一句：*“今天帮我顺便留意下股市、大宗商品和突发新闻，有异动喊我。”*
  2. 下午用户正在 Harness 里写一份完全与股票无关的工作文档，Harness 里挂载的新闻/舆情信源（如华尔街日报、财联社、X）突然推送某重要人物突发讲话或大宗商品异动。
  3. 用户瞬间意识到这与自己的持仓或某板块机会强相关——**完全不需要切出当前工作窗口，更不需要去点开 AI 涨乐**，直接原地对 Harness 说一句：*“这波利好我关注的板块，按现价帮我买两成仓位。”*
  4. 涨乐 Agent 当场在侧边浮现极简确认条，客户轻轻一滑完成委托，下一秒继续写他的工作文档。**金融服务第一次真正嵌进了用户的全天候生命流。**

### 场景 B：破解“90% 非核心与运营功能无法 AI 化”死结，真正实现“千人千面”
* **客观现状：头部 10% 已重构，但 90% 长尾与活动仍是老式页面**
  在现有 `AI 涨乐` 中，研发团队已经把行情、资讯、会话内动态生成盯盘条件单等**最高频核心能力**打磨出了很好的卡片体验。然而，券商拥有极其庞大的非高频业务与常态化运营活动——**以我们正在做的《智投实盘系列赛》（交易大赛）为例**（含周度循环赛、季度价投赛、AI 协同大师赛等赛区），由于存量与新增活动太多、排期太紧，根本不可能把几百个业务全部用原生 AI 模块重构一遍。结果用户一点进活动入口，瞬间掉回老一套静态 H5 页面（所有人看同一张死板页面、手点选赛区参赛），对话框在此完全失灵。
* **2.0 真 Agent 的破局：零预开发页面，实时生成“千人千面”卡片**
  * **为什么现在能做到了？** 过去靠公司中心化算力实时生成 UI 既太慢又太贵；现在依托**每位用户自有的 Harness 模型算力**，客户端实时渲染专属卡片的瓶颈彻底消失。
  * **《智投实盘系列赛》真实闭环（对未报名达标高手主动报喜出卡）**：
    一位客户平时忙工作压根没关注交易大赛，但涨乐 Agent 发现他本季实盘收益率高达 **+26.4%**，放到正在进行的《智投实盘系列赛·季度价投赛》已达**前 3% 获奖水平**！在合适时机，随身投顾主动温和提示：*“您的本季收益率很高，达到了前 3% 的水平，可以看看我们正在进行的智投实盘大赛，报名之后有机会角逐 30g 金牛与新款 MacBook Pro 等丰厚奖品。”* 同时当场动态生成一张展示**他本人收益曲线 vs 赛区获奖线对比、AI 自动匹配赛区、右滑一键报名**的专属卡片；而对近期浮亏客户则保持安静绝不打扰，**完完全全做到公司领导期望的“千人千面”**。

### 场景 C：像线下营业部投顾当面聊天一样的“高信任增值推荐”
* 在工具型 App 里，用户问完即走，强插营销卡片容易引发反感。
* 而驻留在 Harness 里的涨乐 Agent 拥有持续陪伴上下文与适度授权。当它刚帮客户办完一笔调仓，在自然的交互间隙，像认识多年的**线下营业厅专属投顾**一样主动打招呼：
  > *“嗨，刚那笔调仓已经办妥啦。看你最近这几笔波段节奏踩得很稳，刚好华泰针对你这类持仓结构新上了一套融券锁仓与大宗场内对冲方案，不忙的话要不要我简单聊两句？”*

## 三、 虚拟随身投顾 × 华泰真人投顾：不是替代，而是“十倍放大”的人机协同体系

虚拟随身投顾 Agent 绝不是要取代华泰宝贵的持牌真人投顾团队，而是成为**连接“华泰真人投顾专业大脑”与“客户全天候实盘账户”之间的智能神经桥梁**。围绕财富管理“三分投、七分顾”的本质，双方可形成四大高价值协同闭环：

1. **主动观察专属真人投顾的投资方向，实时与客户持仓“对表”纠偏**  
   * **痛点**：许多客户虽然签约了华泰真人投顾（或关注了明星投顾专栏/组合），但平时上班没空看投顾的晨会纪要、直播复盘或周度调仓观点；即便看了，也不知道怎么换算到自己杂乱的实盘持仓上。  
   * **人机配合**：涨乐随身 Agent 持续订阅客户所绑定**真人投顾发布的最新投资方向、赛道研判与模拟组合调仓动作**，自动与客户当前实盘持仓交叉比对。一旦发现显著背离，主动温和提醒：  
     > *“观察到您签约的华泰李投顾今早更新策略：建议逢高兑现部分高估值算力，将仓位向低波红利央企倾斜。目前您账户中算力板块占比仍达 46%（显著高于投顾建议水位），要不要看看我按李投顾方向为您拟定的微调预案？”*
2. **急跌震荡行情的秒级“心理按摩”与高危情绪分级转接（破解 1 对 500 服务瓶颈）**  
   * **痛点**：市场突发大跌时，1 名真人投顾面对名下数百位同时陷入焦虑的客户，微信和电话根本回不过来，极易造成客户恐慌割肉或投诉流失。  
   * **人机配合**：盘中剧烈震荡时，真人投顾只需录入一段核心定心丸观点，随身 Agent 在数秒内结合每位客户的实际持仓结构生成**千人千面的个性化安抚解读**；同时实时识别高危信号（如客户连续追问割肉、重仓两融逼近警戒线、涉及家庭大额资金变动），立即向真人投顾推送**《客户持仓痛点与情绪简报》**，安排真人投顾精准切入 1v1 深度语音/电话沟通，把宝贵的真人精力用在刀刃上。
3. **买方投顾组合“免手点一键跟调”与投后陪伴归因**  
   * **痛点**：传统模式下真人投顾发出调仓建议后，客户需切去交易界面逐只算股数、填价格手点下单，执行率低导致客户实际收益跑输投顾组合。  
   * **人机配合**：真人投顾更新策略组合时，随身 Agent 自动按客户授权跟投比例生成一张**多标的汇总跟调确认卡**，客户核对后一滑即可完成篮子委托；月末自动出具“真人投顾策略对您账户的净值贡献报告”，显著提升付费投顾续约率。
4. **普惠长尾潜客培育与高净值“带画像温热导流”**  
   * 海量中小散户先由零边际成本的虚拟随身投顾提供高水准日常陪伴；当 Agent 在交互中捕捉到客户资金规模跃升（如新增大额银证转入）或产生复杂资产配置、期权对冲、家族财富规划诉求时，自动按客户的交易性格精准引荐风格最匹配的**华泰持牌真人投顾**完成签约，让单名真人投顾的有效服务半径放大 **5～10 倍**。

## 四、 对【用户增长与平台运营部】的影响：双轨稳进与工作流进化

面对这一历史性转向，我们部门既要保持脚踏实地的清醒认知，又要果断启动面向未来的能力重构：

### 1. 清醒的前提共识：传统 App 绝不会立刻淘汰，“双轨并进”将长期存在
* **客观规律**：绝大多数普通投资者短期内还不会立刻改变使用手机/电脑传统界面的习惯，转向纯 AI 助手的工作方式；同时，现阶段也并非所有用户都拥有充足、稳定的个人 AI 模型算力。
* **基本盘定力**：因此，**围绕传统 App（涨乐财富通、AI 涨乐）的存量用户体验优化、活动支撑与日常平台运营工作绝不能松懈，必须继续稳扎稳打做好**，守住公司最广大的存量客户基本盘。

### 2. 面向“涨乐 Agent”的工作流质变：从“页面交付流水线”转向“智能服务编排与触达中枢”
* **过去熟悉的工作流**：`接业务需求 → 设计固定静态页面 → 拉通前后端排期开发 → 客户端发版交付`（本质是不断堆砌新页面，功能越多越臃肿）。
* **面向涨乐 Agent 的全新工作流**：核心使命转变为**“如何将华泰积累的无数专业服务，最合理、最丝滑地通过 Agent 触达到用户侧”**，重点攻克三大新课题：
  1. **克制编排与上下文动态路由（绝不能一股脑堆过去）**：华泰拥有成百上千项行情、投研、交易与运营服务，如果一股脑塞给 Agent，不仅**剧烈消耗用户算力、挤占宝贵的上下文窗口，还会导致响应变慢与推理失焦**。团队必须设计精巧的“分级意图路由与渐进式 Skill 挂载机制”，让每次对话只按需加载最薄、最准的服务描述。
  2. **深度挖掘契合用户的业务场景（从人找功能到场景找人）**：增长与运营的重心从“设计吸睛 Banner 骗点击”，升级为“定义高价值触发时机与客群匹配规则”（例如识别未报名但高收益客户推荐实盘赛、识别重仓单票客户在财报前夕推荐对冲工具）。
  3. **保障传统存量业务经 Agent 调用顺畅完结（端到端闭环治理）**：大量底层柜台与传统业务原本是为网页表单设计的，团队需做好语义中间层封装、异常兜底与状态机巡检，确保传统业务通过 Agent 调用时**不卡壳、不掉回死胡同网页、100% 顺利闭环**。

### 3. 机遇与挑战并存：释放宝贵人力，回归生产“真正有价值的投资产品”
* 过去大量研发、设计与营销精力被消耗在“为每一个短期活动和边缘功能重复画页面、对接口、发版本”的低水平内耗中。
* 当 UI 呈现交由 Agent 按需动态生成后，我们就能**把部门与华泰的人员力量解放出来，聚焦投入到打磨真正有价值的投资产品、优质投顾策略与深度客群运营上**——无论从**客户长期满意度**，还是从**公司研发与营销资源的投入产出比（ROI）**来看，都将释放巨大的结构性红利。

## 五、 产品技术架构与零信任安全底线

```
[用户日常工作的通用 Harness（Claude / DeepSeek Harness / WorkBuddy / 手机原生 OS 底座）]
     │  依托客户自有大模型算力作为“分布式动态 UI 渲染底座”（零预开发静态卡片）
     ▼  (标准 MCP / Skills 按需渐进式路由挂载 —— 严控上下文体积，绝不一股脑堆砌)
┌──────────────────────────────────────────────────────────────────────┐
│       涨乐随身投顾 Agent 中枢（用户增长与平台运营部轻资产自建编排层）      │
│  • 场景挖掘与分级编排：按语境动态分发华泰服务，挖掘千人千面业务触点        │
│  • 真人投顾协同总线：订阅签约投顾策略方向对表持仓 + 震荡行情分级转接 1v1   │
│  • 传统业务顺畅适配层：消除存量表单卡点，保障底层传统业务调用 100% 闭环    │
└───────────────────────────────┬──────────────────────────────────────┘
                                ▼  (全面复用现有账号鉴权、AI 涨乐与主站成熟接口)
        [华泰公用后端中台（账户 / 柜台 / 行情 / 研究所 / 持牌真人投顾工作台）]
```

### 三条不可妥协的安全与合规红线
1. **消灭繁琐表单 ≠ 取消本人确认**：无论前面多少步参数由 Agent 自动填好，**最终涉及资金划转与委托下单的拍板动作，永远通过独立带外安全签名（本人滑动/生物识别直连柜台）完成**，大模型绝无静默成交权限。
2. **跨插件隐私最小化脱敏**：与外部新闻/大宗商品 Agent 协同分析时，仅传递脱敏标的或方向，绝不向外暴露客户精确资金规模与身份信息。
3. **持牌合规与全链路留痕**：内嵌投资者适当性（C1–C5）硬校验，所有分析依托华泰持牌研究所与签约真人投顾合规框架，沟通与确认全量归档可追溯。

## 六、 站在未来 3–10 年变革前夕：90 天早做准备路线图

这场从“独立软件入口”向“个人 AI 底座 + 随身专业 Agent”的迁徙，注定是**未来三年到十年最重要的业务主线**。我们今天正处在变革爆发的前夕——等全行业格局固化再仓促补课就会彻底被动，现在用精锐小步试点提前探路成本最低、主动权最大：

* **Phase 1（第 1 个月）· 部门新工作流打样（以《智投实盘系列赛》等场景破冰）**
